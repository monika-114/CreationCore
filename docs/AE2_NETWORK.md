# AE2 创造工作台网络版

适用环境：Minecraft 1.21.1、NeoForge 21.1.248、Applied Energistics 2 19.2.18。版本号为 0.2.1-ae2network3。AE2 的 GuideME 依赖按 AE2 自身要求安装。

network3 新增：ME 合成终端的实体九宫格可以直接制作创造工作台专属配方，支持普通点击、Shift 连续合成和从 ME 存储自动补料。同网络必须有在线创造工作台；拆除、断电、缺频道时不能继续取出专属产物，恢复在线后自动刷新原九宫格。无需编码样板即可手动合成。

同时保留 network2 的样板终端普通配方崩溃修复。升级时关闭游戏，移除旧版 Creation Core JAR，仅保留本版；联机时客户端和服务端同步替换。可以继续使用原存档及原有样板。

本版基于原始 buildfix10 单独制作，提供“创造工作台在线授权、原生合成样板、分子装配室执行”的方案。它与 ae2batch1 批量合成器版是两个可选安装包，使用相同模组 ID，安装时替换已有 Creation Core JAR。原有 254 个配方保持不变，不含其他模组兼容或新增合成表。

## 使用方法

1. 用 ME 线缆把创造工作台接入网络。工作台能从各面连接，作为网络设备使用，不提供额外的存储容量。
2. 在启用频道的正常网络中，工作台占用一个频道，待供电、频道及网络启动完成后提供授权。将它接到与 ME 样板编码终端、样板供应器和分子装配室相同的 ME 网络。
3. 打开原有的 ME 样板编码终端，选择合成模式，在九宫格设置创造工作台专属配方，放入空白样板并编码。使用 AE2 原生合成样板；不需要处理样板或创造合成器。
4. 把样板放入连接分子装配室的 ME 样板供应器，使用正常的 ME 合成 CPU、供电和材料储存，在终端请求数量即可批量合成。分子装配室按原本速度运行，可使用 AE2 原生加速卡，也可增加装配室和供应器并行。

配方的排列和物品可通过 JEI 查询。本版保证终端九宫格手动设置与编码；未单独添加专属 JEI 分类向 AE2 终端一键填充的处理器。

## 工作台必须持续在线

专属配方同时在编码和实际执行时检查同网络的在线工作台。已经编码的样板也遵循这一条件。

同一网络至少有一台工作台在线即可授权。放置多台时，每台分别消耗一个频道；只要仍有一台正常在线，专属合成即可继续。

- 拆除工作台、切断连接、失去供电、频道不足或工作台所在区块卸载时，相应网络不再获得授权。
- 已下达的任务可以留在 AE2 等待队列中。装配室暂存的材料及合成进度会保留，授权恢复后继续执行，不需要重新编码。
- 已完成的物品仍可正常输出和回网，暂停限制针对新的合成操作。
- 另一个独立 ME 网络中的工作台不能提供授权。每个需要制作专属配方的独立网络都要有自己的在线工作台。
- 普通工作台配方及其他 AE2 原生样板继续按 AE2 原本规则工作。

唱片复制、空桶、空瓶等返还通过配方原有行为交给 AE2 处理。专属配方未注册为普通工作台配方，普通工作台及原版合成器仍不会因此获得这些配方。

## 不安装 AE2 时

AE2 为可选依赖。未安装时，创造工作台、创造合成器及模组原有功能照常使用，AE2 网络功能不加载。

## 构建与开发测试

Java 21、Gradle 9.2.1。标准 `gradle build` 会从 Modrinth Maven 获取 AE2 的编译接口；AE2 不会被打包进本模组。离线开发可使用 `-Pae2DevJar=<AE2 19.2.18 JAR 绝对路径>`。

`tools/network-checks.init.gradle` 将真实 AE2 测试源码加入独立开发运行。传入 `-Pae2TestMods=<包含 AE2 与 GuideME JAR 的文件夹>` 后运行 `gradle runServer -I tools/network-checks.init.gradle`。检查 `build/network-checks.txt` 的最终通过标记。仅对隔离开发世界运行。
