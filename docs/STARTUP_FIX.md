# compat2 启动修复

## 原因

2026-10-21 19:09:52 的错误报告中，三个失败项均为 NeoForge 依赖版本检查：compat1 要求精妙核心至少 1.5.16、背包至少 3.26.13、存储至少 1.6.7，而实际安装版本为 1.5.2、3.26.5、1.6.0，导致启动在玩法初始化之前终止。

compat2 使用实际安装的旧版 JAR 核对接口、重新编译并验证，将最低版本分别改为 1.5.2、3.26.5、1.6.0。三个模组仍为可选依赖。主 Java 源码、配方、物品 ID 和材质与 compat1 相同，不需要迁移物品。

## 验证

- 使用用户游戏目录中全部第三方模组 JAR 的副本，在独立开发目录启动客户端；成功加载资源并进入主菜单，停留后自动退出。没有启动用户存档或修改原游戏目录。
- 使用实际精妙核心 1.5.2.2343、背包 3.26.5.2171、存储 1.6.0.2136 的组合，通过 42 项兼容功能断言。
- 使用此前验证的精妙核心 1.5.16.2422、背包 3.26.13.2214、存储 1.6.7.2184 的组合，再次验证 42 项兼容功能。
- 不安装兼容模组，验证 23 项基础玩法和 9 项本体流体功能。
- 旧版精妙核心单独安装、仅背包与核心、仅存储与核心，分别验证条件注册、独立创造工作台配方以及兼容类加载。

实际报告随发布包提供。客户端主菜单启动检查不等同于所有兼容界面的人工验收。

## 安装

删除旧版 `creationcore-0.2.3-compat1-neoforge-1.21.1.jar`，放入本次 `creationcore-0.2.3-compat2-neoforge-1.21.1.jar`。同一环境只保留一个创造核心版本。客户端和服务器均使用同版创造核心；当前三个精妙模组可以保留，无需为本次修复更新它们。
