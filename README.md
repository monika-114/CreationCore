# 创造核心 Creation Core

本模组为 Minecraft 添加了除了结构方块，命令方块以外的大部分生存无法获得物品的获取方式。通过一系列的仪式制作创造工作台、创造合成器和挖掘工艺，解锁模组提供的合成方式。

适用于 Minecraft 1.21.1 和 NeoForge，运行需要 Java 21。客户端与服务端均需安装。

## 模组功能

创造工作台和创造合成器为本模组主要的功能方块，支持普通工作台配方及本模组的创造配方。
挖掘工艺是不会损失耐久的通用工具，可用于开采基岩等通常无法破坏的方块，同时拥有转化途径，原木去皮等功能。
模组为生物生成蛋、屏障、光源方块以及多种特殊方块和物品提供生存获取渠道。
安装 JEI 后，可以查询配方与物品介绍。

## 创造工作台的获取流程

1. **从虚空中打捞材料。** 将普通空铁桶丢入虚空，等待转化后的“空”桶返回并拾取。将它合成瓶装“   ”，再制作空白物质。
2. **转化凋灵。** 召唤凋灵，在它出生爆炸前，将空白物质掉落物投入爆炸影响范围会将凋零转换成特殊的凋零。击败发生特殊的凋灵，获得基底物质。
3. **完成末影龙仪式。** 将基底物质放置在末地主岛返回祭坛的中心上，再击败末影龙。基底物质会被转化为创造物质。
4. **将创造物质丢进传送门。** 把创造物质单独放入潜影盒，将潜影盒掉落物投入末地主岛的返回传送门。
5. **获得创造核心。** 返回主世界，在世界出生点附近寻找创造核心实体。靠近后，它会转化为可以拾取的物品。
6. **制作工作站。** 取得创造核心后，使用锻造台制作创造工作台或创造合成器，开始使用创造配方。具体配方可在 JEI 或随附说明文档中查看。


## 模组兼容

所有兼容模组均为可选。未安装相应模组时，创造核心仍可独立运行；对应的升级与兼容配方只在目标模组存在时启用。由于机械动力，超越维度，ae2在该版本没有模组，添加kilt也无法运行或者极易崩溃，所以fabric版本没有制作与这几个模组的兼容

**汤姆的简易存储**：创造工作台和创造合成器均可接入存储网络。网络中包含任意一种设备时，合成终端就能使用创造配方。

**精妙背包与精妙存储**：分别提供适用于各自模组的创造合成升级。安装后，可通过原生合成界面制作创造配方。两个升级拥有独立材质与物品标识，不能跨模组安装，并显示在各自模组的创造模式物品栏中。


## 安装与使用

将模组 JAR 放入游戏的 `mods` 文件夹，同一环境只保留一个创造核心版本。多人游戏中，客户端与服务器应使用一致的版本。安装前请确认所用兼容模组满足安装包声明的版本要求。

源码构建方法见 [BUILDING.md](BUILDING.md)，完整功能说明与合成表见 `docs/recipe_spec.docx`。
